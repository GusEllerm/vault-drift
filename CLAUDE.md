# live-docs

This is a research and design project: an Obsidian vault as agent-first live documentation, where each note is anchored by hash to the code it describes.

**Project memory lives in the Obsidian vault at `live-docs-vault/`. Start every session by reading `live-docs-vault/Start Here.md`** and following its reading order.

- Record durable project knowledge in the vault, following `live-docs-vault/Vault Conventions.md`.
- Keep the user's decisions separate from agent proposals (`live-docs-vault/Decision Log.md`).
- At the end of a session that changed anything, add a log under `live-docs-vault/Sessions/` and update "Current status" in `Start Here.md`.
